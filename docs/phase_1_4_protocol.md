# Phase 1–4 experimental protocol

## Research boundary

These experiments test four increasingly strong claims. They do not claim
general intelligence, unrestricted ontology formation, or superiority to a
monolithic learner with the same combined evidence. Every phase reports a
vector of predicates and retains negative controls rather than converting them
into one favorable score.

## Phase 1 — frozen baseline

The original delayed-capacity experiment is executed without changing its
seeds, horizon, thresholds, cues, or operator family. Its protocol dictionary
is hashed into the report. Confirmatory predicates cover original success,
behavioral ablation, checkpoint/restart, multi-seed transfer, and honest
retention of the negative coalition-versus-isolated result.

The expected result is deliberately mixed: operational concept transfer should
replicate, but ecological synergy should remain non-positive. Passing Phase 1
means faithfully reproducing that mixed result, not making every number
positive.

## Phase 2 — distributed identifiability

Three instances receive disjoint channels from each surface:

1. a delayed binary driver;
2. an independent binary context;
3. the binary consequence.

The consequence is the exclusive-or of the delayed driver and current context.
Because driver and context are independent fair bits, neither is informative
about the consequence in isolation. The consequence-only instance can learn
only a majority baseline. Oracle role and case alignment is permitted in this
phase so that the hypothesis under test is narrowly ecological necessity.

The coalition enumerates lags zero through five and all sixteen binary truth
tables. Success requires unseen-surface accuracy, a large advantage over every
isolated history, loss of that advantage when translation or case alignment is
ablated, and parity with an equal-evidence pooled learner. Parity is important:
the evidence supports distributed identifiability, not a claim that ecological
bookkeeping must outperform direct pooling.

## Phase 3 — learned alignment and scale

The oracle role and capacity metadata are removed. Each surface uses unrelated
channel words and independent physical scales. Capacity is inferred from the
two grounded levels in each channel. All six role permutations are evaluated
by consequence consistency across training surfaces; channel words are never
features in the score. The resulting role-to-owner mapping transfers to the
unseen surface, while its local names remain explicit translation residue.

This is a deliberately bounded alignment result. It assumes binary two-level
channels, stable instance identity, aligned case identifiers, and a hypothesis
class containing the true mechanism. Later work must address continuous noisy
capacity, missing cases, unstable ownership, and genuinely partial mappings.

## Phase 4 — typed operator synthesis

The unrestricted four-entry truth table is replaced by a typed grammar:

- delayed driver references with lags zero through five;
- current context references;
- `and`, `or`, `xor`, and `xnor` composition.

Candidates are selected by predictive accuracy with an explicit complexity
penalty. A recurrent program may crystallize as a macro when storing one
definition plus invocations is shorter than repeatedly storing the expanded
program.

Four interventions distinguish representation from semantics:

1. normal macro invocation;
2. deletion of the human-readable handle while retaining semantics;
3. deletion of executable semantics while retaining the handle;
4. inlining the expanded program.

The expected causal profile is that deleting the name does not change
prediction, deleting semantics destroys the gain, and inlining preserves it.
This establishes operational content but does not yet establish an open-ended
machine-created language: the primitive grammar remains architect supplied.

## Reproducibility and compute accounting

All worlds use local deterministic random generators. Reports expose evidence
points and hypothesis-evaluation counts rather than wall-clock timings, which
vary by machine. The phase CLI emits JSON suitable for archival comparison.

## Next falsifiers

The following remain required before developmental corpus training:

- replace exact binary levels with noisy continuous latent capacity;
- compare learned alignment against representation-learning baselines;
- require an active intervention to distinguish observationally equivalent
  programs;
- let tensions choose whether to investigate, revise, or split;
- serialize operators inside the ecology rather than beside it;
- evaluate hundreds of held-out mechanism families with confidence intervals;
- test whether a generated macro changes later search and investigation, not
  prediction alone.
